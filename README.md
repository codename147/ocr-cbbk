# ocr-cbbk

Cong cu tra cuu va OCR ho so (PDF scan) cho du an giao thong, chay tren Windows.

- Cai dat: `CAI_DAT.bat`; chay: `CHAY_PHAN_MEM.bat`; huong dan: `HUONG_DAN.txt`.
- Can Tesseract va goi ngon ngu `vie.traineddata` (khong kem trong repo, tai rieng va dat vao thu muc `tessdata`).
- `pip install -r requirements.txt`

Luu y: khong dua ho so, ban ve, file Excel hay co so du lieu cua du an vao repo.
